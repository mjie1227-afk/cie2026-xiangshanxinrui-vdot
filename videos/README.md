# 三阶段演示视频

3份视频分别介绍环境与向量执行过程、指令设计与基础测试、协同验证与性能分析，对应[三阶段技术报告](../docs/README.md)。

| 阶段 | 视频文件 | 时长 |
| --- | --- | --- |
| 阶段1 | `第一阶段的操作过程录屏.mp4` | 09:35 |
| 阶段2 | `第二阶段的设计文档和基础测试文档.mp4` | 10:22 |
| 阶段3 | `第三阶段的基于波形仿真和性能分析录屏.mp4` | 15:22 |

视频均为1920×1080、30帧/秒，包含讲解音频。

视频使用Git LFS随仓库管理。在已安装Git LFS的机器上克隆仓库后，进入仓库根目录执行：

```powershell
git lfs pull
```

下载完成后直接打开对应MP4观看。项目提供的完整交付ZIP也包含这3份原始视频。
