# 1 项目概述与任务对应

本项目为香山昆明湖 V2 增加了 `vdot.vv` 指令。它从两个向量寄存器中各取八个有符号 8 位数，逐项相乘，再把八个乘积加起来。处理器用一个微操作完成这次点积，结果通过原有的向量写回和退休通路提交。NEMU 参考模型也加入了相同的指令规则，用于逐次核对硬件运行结果。

边缘 LLM 的 INT8 线性层反复计算输入与权重的点积。本项目把八项点积放入流水线中的专用功能单元，沿用向量寄存器、重命名、发射、写回和退休机制，再用软件累加多个部分和，完成较长的点积。

报告按工程实施内容分为三个阶段。第一阶段说明环境部署、程序运行及 VADD 执行过程；第二阶段给出指令规格、硬件结构、RTL 接入和功能测试；第三阶段说明参考模型、差分检查与性能测量。源码、原始日志和波形材料通过各阶段附录定位。

## 1.1 计算目标与工程方案

设两个源寄存器的低八个字节分别为有符号整数 a₀…a₇ 和 b₀…b₇，无掩码操作计算：

```text
S = a₀b₀ + a₁b₁ + … + a₇b₇
```

八个乘积从零开始求和，不把目的寄存器的旧值加进去。硬件先用八路乘法器同时计算，再用三级加法树求和；第一拍保存乘积，第二拍保存整理好的结果。输入怎样从内存装入、结果何时存回、多次点积能否共用输入，都由程序安排。因此，性能测试既测寄存器已经备好数据时的计算，也测包含加载和存储的完整任务。

设计以赛题规定的固定八项 INT8、归约初值为零和其余输出清零为基础。项目进一步定义编码、掩码、有效长度、寄存器重叠和状态更新规则，形成 RTL、NEMU 与测试共同采用的指令规格，具体定义见第 4 章。

## 1.2 主要技术结果

在指定处理器配置下，基础算术、异常、寄存器重叠和流水场景均已完成整核差分检查。标准 RVV 等价实验组合了 144 组输入配置，三条实现共执行 432 次内核调用。波形分析另对正常执行、投机取消、退休状态请求及发射前资源竞争进行了动态指令追踪。

让后一次点积读取前一次的结果，连续执行时，每增加一次操作，VDot 需要增加 7 周期，RVV-m1 和 RVV-mf2 分别增加 55、47 周期。两条 RVV 路径与 VDot 的延迟比分别为 7.86 和 6.71。统计包含各实现为得到相同结果而执行的配置、计算和结果整理。单独看 VDot 功能单元，从接受输入到完成计算为 2 周期；这段时间在第 6 章的波形中测量。

把输入加载和结果存储也算进去后，初版程序执行 128 次点积，VDot/RVV-mf2 用 2239/2241 周期，耗时基本相同。双方都优化加载安排后，G=16 分段任务的周期比为 1.24。双方都复用输入时，2×2、K=256 内核用 790/1043 周期，周期比为 1.32，VDot 耗时少 24.3%。第 9 章分析这些结果与 INT8 线性层的联系；完整模型的生成速度还需计入量化处理、矩阵遍历及运行时开销。
