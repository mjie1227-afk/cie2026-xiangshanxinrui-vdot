# 1 项目概述与任务对应

本项目在香山昆明湖 V2 中实现一条固定八项有符号 INT8 点积指令 `vdot.vv`。它将八组乘法、归约和结果整理合并为一个微操作，复用处理器已有的向量寄存器、调度、写回和退休机制。项目同时扩展 NEMU 参考模型，以整核差分仿真验证架构行为，并构造两条标准 RVV 指令组合，比较完成相同操作的执行成本。

工作的起点是明确指令应当怎样计算，终点是解释它在处理器中怎样执行、在哪些软件组织下产生收益。报告据此分为三个阶段：第一阶段建立可运行、可观察的实验环境；第二阶段给出指令设计、RTL 接入与功能测试；第三阶段用参考模型和等价基线检查正确性并分析性能。

## 1.1 计算目标与工程方案

设两个源寄存器的低八个字节分别为有符号整数 a₀…a₇ 和 b₀…b₇，无掩码操作计算：

```text
S = a₀b₀ + a₁b₁ + … + a₇b₇
```

点积从零开始归约，旧目的不参与累加。硬件采用八路并行乘法和三级加法树，两个流水级分别保存乘积和格式化结果。指令不直接访问内存；源数据装载、结果存储及多次点积之间的数据复用由软件完成。因此，评价方案时需要同时观察寄存器内操作和带数据搬运的内核。

赛题明确规定的固定八项 INT8 运算、归约初值和其余输出清零，构成设计基础。编码、掩码、有效长度边界、寄存器重叠及状态更新由项目补充为实现规格，并由 RTL、NEMU 和测试共同遵循。第 4 章集中解释这些规定与设计理由。

## 1.2 主要技术结果

指定配置下，基础算术、异常、寄存器重叠和流水场景已有整核差分记录；标准 RVV 等价验证采用 144 组输入配置，三条路径共执行 432 次内核调用。内部波形进一步关联了正常执行、投机取消、退休状态请求及发射前资源竞争的动态实例。

依赖链测量得到的延迟如下：完整操作依赖链中，每增加一次点积，VDot 增加 7 周期，RVV-m1 和 RVV-mf2 分别增加 55、47 周期，延迟加速比为 7.86、6.71。这里的完整操作包括各实现满足相同接口所需的工作；VDot 功能单元自身的输入到完成间隔为 2 周期，二者在报告中分别说明。

带访存的结果显示了软件组织的重要性。初版逐点输出内核在 128 次点积时，VDot 与 RVV-mf2 分别为 2239、2241 周期，基本持平。进一步在各自相同输出的对照内改善输入加载及共享输入，得到相对同等优化 RVV-mf2 的 1.24 倍和 1.32 倍整窗比。这些结果分别对应不同的输出任务，不合并为一个通用应用加速比。
