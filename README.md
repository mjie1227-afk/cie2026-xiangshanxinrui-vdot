# 香山芯锐：昆明湖 V2 自定义 vdot.vv

2026 CIE 全国 RISC-V 高水平创新及应用大赛参赛工程。

## 团队与项目信息

- **团队名称**：香山芯锐
- **参赛单位**：西安电子科技大学集成电路学部
- **队伍成员**：梅杰、张磊磊
- **赛题**：面向边缘 AI 大语言模型推理的 RISC-V 自定义 vdot 指令设计

本项目在香山昆明湖 V2 的向量后端集成专用点积单元，通过 `vdot.vv` 完成固定八项有符号 INT8 点积，为边缘 LLM 的量化线性计算提供算子级加速。项目同步扩展 NEMU 参考模型，完成整核差分验证，并使用标准 RVV 等价实现比较指令延迟与含访存内核的性能。

## 实现和主要结果

`vdot.vv` 计算源寄存器低八项 signed INT8 的乘积和，精确结果写入低 32 位，高 96 位清零。硬件使用八路乘法与三级加法树，两拍完成 FU 数据通路；译码、源依赖、异常指令字和退休状态处理接入既有后端。完整规格见[第 4 章](docs/正文/04_指令规格与微架构设计.md)。

在固定单核 MinimalConfig、VLEN=128 下，已保存的整核记录包括基础功能 7 例、异常套件 64 例、寄存器重叠 60 例、流水场景 120 例。两条标准 RVV 基线在 144 种输入配置、432 次内核调用中通过等价检查。

| 测量 | VDot | RVV-m1 / RVV-mf2 | 结果含义 |
| --- | --- | --- | --- |
| 完整操作依赖链增量 | 7 周期/次 | 55 / 47 周期/次 | 延迟比 7.86 / 6.71 |
| 八路批处理 N=128 | 216 周期 | 906 / 519 周期 | 整窗比 4.19 / 2.40 |
| 逐点输出小数组 N=128 | 2239 周期 | 2249 / 2241 周期 | 与 RVV-mf2 基本持平 |
| G=16、同等加载优化 | 1089 周期 | RVV-mf2：1355 周期 | 整窗比 1.24 |
| 2×2、同等输入复用 | 790 周期 | RVV-mf2：1043 周期 | 整窗比 1.32 |

后三项各有自己的输出任务和计时窗口。详细样本、预热与方法见[第 9 章](docs/正文/09_延迟测量与软件优化分析.md)。

## 编译与复现

从新下载的仓库开始，按[复现指南](REPRODUCE.md)依次完成环境准备、编译、基础测试、功能测试、性能测试和结果导出。Windows PowerShell和Linux使用同一套脚本，工具链由Docker环境自动安装。每一步的成功标志和结果位置均在指南中列出。

仓库包含已应用VDot和mtval修改的完整XiangShan、NEMU、nexus-am及所需源码依赖。准备脚本直接生成编译目录，无需再次应用补丁；首次环境搭建和编译需要联网获取工具及Scala/Chisel依赖。源码组织和许可证见[SOURCE_TREE.md](SOURCE_TREE.md)，已有测试结果与日志见[验证说明](VALIDATION.md)。

3份演示视频使用 Git LFS 随仓库管理。克隆后运行 `git lfs pull`，即可打开MP4观看；详情见[视频目录](videos/README.md)。
