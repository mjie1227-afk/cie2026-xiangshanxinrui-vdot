# 第三阶段复现环境、产物哈希与材料路径索引

正文包含构建方法、核心实现与实验结果。本附录用于核对版本、识别运行产物和定位完整工程材料。

## 1 复现环境与源码版本

表 S3-A1　环境、配置与源码版本。

| 对象 | 配置或版本 |
|---|---|
| 平台与工具 | SCNet Linux 服务器；JDK 21、Mill 0.12.3、Verilator 5.052；应用使用服务器 RISC-V GNU 工具链 |
| 整核配置 | 单核 MinimalConfig、VLEN=128、EMU_TRACE=1；性能运行 seed=1 |
| XiangShan 基版本 | `16ae9ddcda54fc9a2fddffad73174cf793ac7814`，叠加完整 VDot 与 mtval 修复补丁 |
| NEMU 基版本 | `a48a11f208ff81ad765591d83271d1b339fb3861`，叠加 vdot.vv 参考语义 |
| 状态交换 | 固定配置 regcpy 源码布局为 1400 字节，向量区为 512 字节；方法见第 8 章 |
| 应用接口 | 等价验证与三类性能负载分别编译，计时窗口和样本数见第 10 章 |
