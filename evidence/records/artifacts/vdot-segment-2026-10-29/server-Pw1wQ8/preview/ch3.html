2 方法

2.1 部署与构建关系

从源码到可执行程序分为三层：Mill/Chisel 生成 RTL，Verilator 与 C++ 编译器生成整核仿真器，RISC-V 交叉工具链生成由仿真器加载的应用镜像。表 3-2 给出部署顺序。

表 3-2　部署步骤及生成产物。

阶段 操作与产物
工具准备 安装 OpenJDK 21、RISC-V 交叉工具链、LLVM/Clang 19 及构建依赖；最终使用 Verilator 5.052
源码获取 2026-10-12 19:27:43，从官方仓库克隆 xs-env；各仓库版本见第一阶段复现索引
环境载入 使用 env.sh 配置工程路径，准备 AM 应用及 DiffTest 参考库
RTL 生成 Mill 执行 top.SimTop，以 MinimalConfig 生成 SystemVerilog
仿真器生成 Verilator 将 RTL 转换为 C++ 模型，再编译链接得到 build/emu
应用构建 RISC-V 工具链将 C/汇编编译为 .elf、.bin 及反汇编文件，emu 加载 .bin 执行

初次恢复构建时，C++ 编译因 clang++: No such file or directory 以 Error 127 中止。Clang 已安装在 /usr/local/llvm/bin，将该目录加入 PATH 后继续构建，RTL 生成、Verilator 转换与 C++ 编译三个阶段均以退出码 0 完成。

以下为实验采用的 WSL/Bash 构建命令；工作目录是当时的 XiangShan 仓库：

cd /mnt/d/Mayyyyyy/WorkSpaces/VScode/xs-env/XiangShan
export PATH="/usr/local/llvm/bin:$PATH"
make emu CONFIG=MinimalConfig EMU_TRACE=1 JVM_XMX=6G -j4

CONFIG=MinimalConfig 选择单核配置，EMU_TRACE=1 使仿真器支持导出波形，JVM_XMX=6G 限制 JVM 堆，-j4 限制并行编译数。生成的 build/emu 包含硬件模型；修改 Hello 的打印内容只需重新编译应用镜像。

2.2 Hello 程序与通过条件

Hello 通过 AM 的 printf 输出个人标识与当次 WSL IPv4，正常返回 0。2026-10-19 采集的地址为 172.26.232.122，打印语句为：

printf("hello xiangshan, I am Meijie, IP address: 172.26.232.122\n");

应用采用 ARCH=riscv64-xs、LINUX_GNU_TOOLCHAIN=1、MARCH=rv64gcv，生成 hello-meijie-riscv64-xs.bin。emu 加载镜像并显式指定 NEMU 参考库，以种子 1、最大运行周期 100000 执行。通过条件为输出与 IP 记录一致、DiffTest 启用、出现 GOOD TRAP 且退出码为 0。

先构建 AM 应用，再把生成的 .bin 交给 emu。下列命令在 WSL/Bash 执行；AM_HOME 指向 Linux 文件系统中的 AM 工程。

export AM_HOME=/home/lenovo1227/xiangshan-learning/nexus-am
cd "$AM_HOME/apps/hello-meijie"
make ARCH=riscv64-xs LINUX_GNU_TOOLCHAIN=1 MARCH=rv64gcv -j2

ARCH=riscv64-xs 选择香山 AM 环境，LINUX_GNU_TOOLCHAIN=1 选择工具链前缀，MARCH=rv64gcv 沿用本次应用的指令集配置。以下加载归档镜像，并显式连接差分参考库：

XS_ENV=/mnt/d/Mayyyyyy/WorkSpaces/VScode/xs-env
RUN_DIR='/mnt/d/Mayyyyyy/WorkSpaces/日常工作区1/2026比赛规划/RISCV_vdot/artifacts/runs/S1-01/hello-meijie-20261019-120654-8FtdkQ'
cd "$XS_ENV/XiangShan"
./build/emu \
  -i "$RUN_DIR/hello-meijie-riscv64-xs.bin" \
  --diff "$XS_ENV/XiangShan/ready-to-run/riscv64-nemu-interpreter-so" \
  --no-snapshot -C 100000 -s 1

-i 指定镜像，--diff 指定 NEMU 共享库，--no-snapshot 关闭快照，-C 100000 设置仿真周期上限，-s 1 固定种子。只有正确打印、GOOD TRAP 和退出码 0 同时出现，才判定本次程序运行通过。

证据：Hello 源码与运行目录 · 完整命令与退出记录
