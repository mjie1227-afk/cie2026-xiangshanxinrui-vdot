## 重新导出（WSL/Bash）

已经生成的文件可以直接打开。以下命令用于亲自复现，每次创建新目录，保留旧波形。

```bash
export AM_HOME="$HOME/xiangshan-learning/nexus-am"
XS_ENV=/mnt/d/Mayyyyyy/WorkSpaces/VScode/xs-env
mkdir -p "$HOME/xiangshan-learning/waves"
wave_dir=$(mktemp -d "$HOME/xiangshan-learning/waves/vadd4-XXXXXX")
cd "$XS_ENV/XiangShan"
./build/emu \
  -i "$AM_HOME/apps/vadd4/build/vadd4-riscv64-xs.bin" \
  --diff "$XS_ENV/XiangShan/ready-to-run/riscv64-nemu-interpreter-so" \
  --no-snapshot --dump-wave-full \
  --wave-path="$wave_dir/vadd4.vcd" \
  -b 0 -e 8000 -C 200000 -s 0 \
  > "$wave_dir/run.log" 2>&1
wave_rc=$?
echo "EMU_EXIT_CODE=$wave_rc"
echo "$wave_dir"
ls -lh "$wave_dir/vadd4.vcd"
grep -E 'Difftest enabled|vadd4:|C\[|PASS|FAIL|GOOD TRAP|BAD TRAP' "$wave_dir/run.log"
```

--dump-wave-full保留时钟高/低相位；-b/-e控制导出的仿真cycle范围，单位不是GTKWave的ps；-C控制整次运行上限。导出前8000周期已覆盖本节目标译码事件，但不宣称包含程序全部执行。实际仿真继续到GOOD TRAP，退出0。

### D. 5277→5278ps：提交映射落地

选择`inner_ctrlBlock.rat.vecRat`，添加：

写回把结果放进物理寄存器；提交按程序顺序确认指令成为已提交状态。在本实现中，ROB的提交信息经过RAB传到体系结构映射表，故ROB退休5274ps与映射表更新5278ps分开记录。提交不是再把128位结果搬到另一份名为v3的数据寄存器；arch_table_3保存的是物理编号，不是计算结果。
